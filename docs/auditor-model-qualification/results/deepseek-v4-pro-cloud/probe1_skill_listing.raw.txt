Available actions:
  lint                 — Lint all yaml+symbolic blocks for consistency, completeness, and gate compliance.
  analyze              — Full symbolic analysis across all yaml+symbolic blocks including v2.0 sections.
  gates                — Pipeline view with gate conditions. Show gates and their evidence requirements.
  export               — Export symbolic models to static formats (mermaid, dot, html).
  watch                — Watch work-state and auto-regenerate HTML report. Polls for changes.
  extract              — Extract symbolic models from all files or a single skill. Outputs structured JSON.
  verify-structure     — Extract and classify structural components from target files against spec requirements. Outputs classification table. Agent verifies substance with live reads.
  verify-acceptance    — Extract and classify acceptance criteria from spec files. Supports SC-N: prefix, [ ] checkboxes, ## Success/Acceptance Criteria sections. Outputs classification table. Agent verifies substance with live reads.
  verify-issue         — Extract structural requirements + acceptance criteria from GitHub issue body. Agent fetches body via GitHub MCP (github_issue_read) and passes it via --body or --body-file. Tool extracts and classifies; agent verifies substance with live reads.

Analysis modules:
  exhaustive           — Exhaustive pairwise SAT analysis — finds undeclared contradictions where two rules say HALT and PROCEED under overlapping conditions.
  entailment           — Pre/post entailment checking — finds contract gaps where upstream postconditions don't satisfy downstream preconditions.
  guards               — Guard completeness and disjointness per state machine — finds dead states and non-deterministic routing.
  enforcement          — Maps critical rules from 000-critical-rules.md to skill task enforcement checkpoints. Finds rules with no enforcement.
  triggers             — Trigger keyword ambiguity detection — finds multiply-claimed keywords where N>1 skills share the same trigger.
  decomposition        — Missing mandatory decomposition entries — finds dispatch chain steps missing mandatory:true decomposition entries in task contracts.
